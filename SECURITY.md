# Seguridad

Esta aplicación es un MVP para desarrollo y pilotos controlados. Todavía NO cuenta con todos los requisitos para lanzamiento comercial público. Revisa `PENDIENTES-PARA-PRODUCCION.md`.

No publiques en issues contraseñas, claves API, cookies de sesión, datos personales ni bases de datos. Si detectas una vulnerabilidad, comunícala de forma privada al propietario del repositorio por un medio de contacto autorizado.

Antes de desplegar en producción: HTTPS, secretos protegidos, copias de seguridad y restauración verificadas, revisión de permisos y privacidad, y análisis de seguridad independiente.
