PREGUNTAS FRECUENTES

Las cosas claras, desde el inicio.

Conoce qué puedes probar hoy y cómo seguirá creciendo Centro I.A.

¿Centro I.A. es una aplicación para clientes o empresas? +

Para ambos. Los clientes encuentran negocios, puntos y recompensas. Las empresas organizan sus programas de fidelidad y consultan su actividad.

¿La versión de GitHub Pages usa cuentas reales? +

No. GitHub Pages muestra una demo interactiva con datos ficticios almacenados en tu navegador. El proyecto incluye además un backend local separado que requiere hosting compatible para conectarse con usuarios reales.

¿Se pueden usar o pagar recompensas reales? +

Los premios, cupones y puntos del sitio público son simulaciones. Los canjes reales requieren integrar la nueva interfaz con el servidor y validar las operaciones antes de publicarlas.

¿La inteligencia artificial ya envía campañas? +

No. La demo prepara borradores de campañas. El backend incluye funciones de análisis y una integración opcional de IA, pero el envío real por correo, SMS y WhatsApp sigue pendiente.
